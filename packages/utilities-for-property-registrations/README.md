## API

[Read the API docs](./docs/utilities-for-property-registrations.md)

## Usage

Add [Utilities for Property Registrations] to your project:

```bash
npm install @csstools/utilities-for-property-registrations --save-dev
```

```ts
import {
	collectPropertyRegistrations,
	hoistPropertyRegistrations,
} from '@csstools/utilities-for-property-registrations';
```
